# Internship Portfolio Website

This project was reconstructed from the supplied ZIP containing the `src` React components.

## Run in VS Code

1. Install Node.js (LTS) if it is not already installed.
2. Open this folder in VS Code.
3. Open Terminal in VS Code.
4. Run:
   npm install
5. Start:
   npm run dev
6. Open the localhost URL shown by Vite.

If an original image/asset is missing, replace the placeholder/missing asset with the original file from the class project.

## Project structure

- `index.html` — browser entry page
- `src/main.jsx` — React entry point
- `src/App.jsx` — main application
- `src/components/` — individual portfolio sections
- `src/*.css` and component CSS — styling
- `package.json` — dependencies and scripts
- `vite.config.js` — Vite configuration
